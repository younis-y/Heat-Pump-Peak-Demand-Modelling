Three of the four files here are generated by the pipeline. One is third-party
data that this repository redistributes, and it is not covered by the MIT
licence in `LICENSE`.

## Third-party

Copyright in this file is not held by the author of this repository. The TMYx
series is published for free download by Climate.OneBuilding.org, but the site
does not attach an explicit redistribution licence to individual EPW files, and
no licence text ships inside the EPW header. **Redistribution terms have not
been confirmed.** Anyone reusing this repository should check the terms at
climate.onebuilding.org and, if in doubt, download the file directly from there
rather than relying on the copy bundled here.

The file is bundled so that `python main.py` reproduces the published figures
without a download step. It is used read-only; nothing in the pipeline modifies
it.

## Generated

`weather_W1.csv`, `weather_W2.csv`, `weather_W3.csv` are 24-hour profiles
extracted from the EPW file above by `main.py` for the three weather
scenarios defined in `config/simulation_config.yaml`. They are rewritten on
every run and are derived work of the EPW file, so the same caveat applies.
